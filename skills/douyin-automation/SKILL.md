# 抖音自动化skill

## V3 配音和花字的最高优先规则

**用户明确禁止 macOS 自带机械配音与系统字幕。** 新视频默认以 Qwen3-TTS MLX 产生真实中文 AI 配音（或有权限且已实测可用的剪映免费中文音色），以 Remotion 在正式 MP4 直接绘制逐词高亮、描边、阴影与弹性强调的动态花字。不得用 `say`、Swift 原生字幕或静态 SRT 自动样式顶替。先读 [无人值守生产流程](references/autonomous-production.md) 中“脚本与真实 AI 口播”和“花字与音频同步”，再开始视频。所有配音、花字均按实际口播的帧级时间线制作；失败阻塞，不偷换低质替代方案。用户仍只负责发布。

## V2 默认模式：Codex 全自动制作，人手发布

**当前账号最新明确要求：选题、实测、录屏、脚本、配音、分镜、动效、成片、质检和封面均由 Codex 自主完成；用户只负责亲自发布。** 优先完整阅读 [无人值守生产流程](references/autonomous-production.md)，其与本文件、旧剪映资源门禁或角色指令冲突时以该文件为准。新项目默认 Remotion 最终渲染，**剪映不是必经步骤**；用户特别要求剪映时才启用旧路径。不得操作用户的抖音/小红书账户、发布、预约、上传草稿或自动互动。任何需要付款、额外登录或执行危险代码的步骤都应安全降级、换题或如实阻塞。

执行默认流程：**自动选题 → 仓库风险审查 → 隔离实测与真实录屏 → 证据约束的口播 → 实际 TTS 音频 → 逐镜时间轴 → Remotion 代码动画与真实画面融合 → 短样 → 正式 MP4 → 机器及可用模型审查 → 失败返工 → 待人工发布交付包**。

**强制区分：** 有 Remotion 文档不等于实际运行 Remotion；有 ffprobe 报告不等于视觉/音频审查通过；有输出文件不等于允许发布。不能生成或审查时说明阻塞，不伪称完成。

唯一用户入口。主 Agent 管理阶段、项目清单、授权和最终交付；热点运营、导演、自动剪辑按需承担专业阶段。凡抖音视频制作，先读 [抖音留存优先规则](references/douyin-retention.md)，并让它优先于通用节奏模板。

## 真实照片与代码动效

用户提供参考片并要求真实网上素材、镜头只用一次、图标有动作、代码生成动画时，先读 [真实素材与代码动效剪法](references/evidence-led-editing.md)。先看片和逐句配证据，再选可复用动效组件。技术题同时沿用下方分支。

## 技术讲解分支

GitHub Skill、CLI、代码、架构、排查或技术演示为主时，先读 [技术讲解制作流程](references/technical-explainer.md)，再沿用本页的通用调度和剪映交付。GitHub 高星 AI Skill 视频或明确要求动态技术演示时，执行 [动画制作流程](references/github-skill-motion.md)，Remotion 优先，HyperFrames 或适合的逐帧引擎备选。将明确的无导流、脱敏和封面措辞要求同步到画面、口播、字幕、标题和发布文案。

## 调度

1. 按需复制 `templates/project-manifest.json` 到 `~/Desktop/视频/<项目名>`；用户指定目录时优先使用指定位置。素材、录屏、工程、封面、成片和 QA 记录归入项目目录。
2. 确认平台、目标人群、主题、时长、素材、软件、授权和交付形式。用户已给选题/脚本时跳过对应阶段，只补缺少的证据或制作步骤。
3. 按依赖顺序执行：热点 → 导演 → 剪辑。每次只调用一个子 Agent，等该阶段交接后再继续；只加载当前角色文件和其需要的参考，不要把整包、测试或脚本源码全部读入上下文。主 Agent 将状态写回项目清单，并检查 `references/handoff-contract.md`。
4. 会话提供原生子 Agent 时，把对应 `agents/*.md` 交给真实子 Agent；没有时在同一窗口按角色指令依次工作，不声称并发。子 Agent 不发布、不绕过权限、不擅自使用收费服务；主 Agent 负责汇总和最终复核。
5. 制作任务按 `references/douyin-retention.md` 与 `references/creative-quality.md` 执行：第一帧给钩子、5 秒内兑现、紧凑镜头、克制字幕和声音、问句收尾；再做真实画面核验、逐镜头声画设计、剪映资源检查和最终看听验收。用户给稿也要检查钩子和口播；研究清单任务不强制进入制作。每阶段运行 `scripts/validate_project.py --stage script|director|edit|final`，失败不得进入下一阶段；主控分派具体返工并复检。

## 证据与权限

- 热点、受众和脚本主张按 `agents/hotspot-operator.md` 记录来源、观察时间、样本、指标原值/单位和依据。缺数据留空而非填 0；区分事实、推断、创作判断。没有平台数据时标为有限验证或候选题，不编造趋势、受众画像或播放结果。
- 只用获准且可访问的来源。遇到登录、验证码、风控、权限或付费门槛时停止该来源并说明限制；不绕过、不自动互动或发布。付费 API、生成积分、账号操作和外部发布需本期明确授权。
- AI 生成画面标为概念内容，不能代替真实网页、产品、录屏或实测。金额、功能和实测结论都要有对应证据。

## 制作与交付

- 自动剪辑实操读 [自动剪辑与质检](references/automatic-editing.md)。按「选题 → 钩子 → 口播 → 分镜 → 素材 → 配音 → 音频时间轴 → 镜头 → 字幕 → 音乐音效 → 检测 → 导出」执行。优先真实录屏、实拍和过程演示。显著静态只作有限解释，缺少核心证据应补素材。
- 用 `scripts/auto_edit.py` 运行逐镜预渲染和九项质检，输出可分轨导入剪映的素材。试剪 10–15 秒通过再做完整片。动画分支先用代码引擎生成动效镜头和带声字幕预览，再将画面及分轨送剪映。自动化预览注明 FFmpeg 来源，剪映交付以实际剪映组装和导出为准。

- 导演遵循包内 `modules/douyin-style-director/` 和 `agents/director.md`：首帧用真实画面兑现钩子，中段呈现真实滚屏与短字幕，少用文字卡；输出七份 JSON 方案，并把未拍/未录素材标为缺失。
- 旧版剪映兼容分支可使用桌面剪映专业版，口播从剪映已实测能免费生成的中文音色中选择；缺少剪映配音时报告阻塞。选择剪映分支时核验免费中文配音、字幕花字、转场特效、音乐和音效及许可；按 `agents/video-editor.md` 执行。默认新项目使用 Remotion，无需引擎覆盖授权；只有显式选择剪映才执行其资源门禁。剪映工作流须由剪映导出；Remotion、FFmpeg 或其他工具不能冒充剪映成片。保留可编辑工程、依赖说明、素材授权、MP4、封面和 QA 记录；没导出/没工程就不得标完成。
- 抖音视频默认 9:16；封面横版 4:3（1440×1080）、竖版 3:4（1080×1440）。需要人物时沿用用户提供的卷发、细黑框眼镜男生参考。免费且许可范围清楚的音乐压在口播下；素材与成片默认存桌面「视频」文件夹。
- 主 Agent 按抖音留存规则检查 0–2 秒钩子、2–5 秒兑现、全片节奏、字幕、人声、音乐、转场、问句结尾及单独的封面标题；未达标就改稿或重剪并复检。最终必须真实审查视频与音频才能通过观感 QA；无人值守模式可由具备真实媒体感知能力的 Codex 记录自动观察证据，无法审查时不得虚填通过；脚本和 ffprobe 只验证结构/媒体信息，不能证明事实、授权或观感。发布始终由用户明确授权。

## 检查

项目清单结构检查（不等同创意通过）：`python3 scripts/validate_project.py <项目目录>/project-manifest.json --root <项目目录>`；有真实素材路径时加 `--check-files`。渲染后可用 `python3 scripts/inspect_render.py <视频.mp4> --expect-width 1080 --expect-height 1920 --expect-duration 30`，按需加 `--require-audio`。脚本不联网取数、不渲染视频、不替代人工 QA。

`agents/openai.yaml` 只配置展示名和提示。Agents API 多 Agent 需由会话创建方开启；参见 `references/native-multi-agent.md`。
