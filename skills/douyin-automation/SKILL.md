# 抖音自动化skill

这是唯一的用户入口。主 Agent 负责需求、阶段顺序、文件、权限与最终检查；热点运营、导演、自动剪辑是内部专业角色，不要求用户切换窗口。

## 工作方式

1. 读取 `templates/project-manifest.json`，为本期建立项目记录；默认输出到 `~/Desktop/视频/<项目名>`，用户指定目录时以用户指定为准。素材、原始录屏、可编辑工程、封面和 MP4 放在同一项目目录。
2. 先确认平台、目标人群、主题、时长、素材、编辑软件、授权和交付形式。用户已给出脚本或选题时，不重复研究；只补齐缺少的证据。
3. 按 `agents/hotspot-operator.md` 完成选题与脚本，按 `agents/director.md` 设计分镜，再按 `agents/video-editor.md` 执行剪辑。角色输出和交接字段见 `references/handoff-contract.md`。
4. 在当前 Codex 会话提供原生子 Agent 工具时，主 Agent 读取对应角色文件并实际调用子 Agent。按依赖顺序执行：热点研究完成后再导演，导演方案完成后再剪辑；只并行互不依赖的审查任务。等待结果并复核来源及文件。若当前会话没有子 Agent 工具，主 Agent 在同一窗口依次按三个角色文件轮换，不声称并发。
5. 子 Agent 只产出分配的阶段成果，不发布、不发送外部消息、不创建付费服务、不消耗生成积分。主 Agent 汇总版本、解决冲突、更新项目清单并做最终 QA。

本 Skill 的 `agents/openai.yaml` 只设置展示名和调用提示，不会开启多 Agent。读取 `references/native-multi-agent.md` 了解运行时配置边界。可用的原生协作能力由当前会话决定；OpenAI Agents API 会话需由创建会话的一方设置 `agent.multi_agent.enabled=true`，并可将并发数设为 3。没有该运行时能力时按上面的单 Agent 轮换方式工作。

## 真实证据与降级

- 实时热点必须记录可打开的来源链接、平台、作品/话题、发布时间（未知则留空）、观察时间（含时区）、受众依据、样本范围，以及每项可见互动/播放指标的原始值和单位。
- 点赞、收藏、评论、分享、播放和热榜指数分开记；缺项留空，不以 0 代替。一次快照不证明增长趋势；增长需有可比的多个观测点。评论只能支持受众需求推断，不能冒充后台人口统计。
- 来源只有新闻而没有平台热度时，写“候选选题，平台热度未验证”；没有登录/API/授权时，写明缺口并做有限公开样本或常青选题。验证码、风控、付费授权缺失或服务错误时停止该来源，不绕过、不反复试。
- 把事实、推断、创作假设分开。流量数据和受众推断不能写成确定结论；“爆款”只表示创作目标，不承诺播放量或转化。
- 抖音数据抓取和小红书 MCP 都是可选来源，不是默认安装项。未获授权时不登录、不使用第三方付费 API。小红书能力若同时包含发布/点赞/评论，只调用有明确只读用途的功能；不自动发布或互动。

## 内容和制作规则

- 开头优先出现真实网页/产品的关键词或可核验结果；中段用真实操作、滚屏和短字幕推进，少用纯文字卡。真实录屏不能由生成界面替代。
- 先兑现看点，再解释原因、展示实测和局限。每个关于功能、金额、性能或实测结果的断言必须能回到证据；未验证时标出。
- 导演遵循现有 `douyin-style-director` 的证据规范和七份 JSON 交接格式；剪辑不能擅自重定整体风格。AI 生成内容须标为概念画面；收费、积分或账号操作先取得本期明确授权。
- 竖屏视频按 9:16；封面横版 4:3、1440×1080，竖版 3:4、1080×1440。封面主角使用用户提供的固定角色参考（如用户要求）；背景与设计可随选题变化，夸张表达不能歪曲内容。
- 音乐、音效及转场素材必须有许可依据并满足目标平台使用范围；优先免费且许可清楚的素材，音乐音量服从口播。不能证明免费或有权使用时不使用。
- 优先使用用户指定的软件和已有工程。原剪映工作流要求在剪映专业版完成正式剪辑；Remotion、FFmpeg、剪映草稿工具仅在本期选择并实际可用时使用。不得把其他渲染器输出说成剪映成片。遇到软件权限或导出阻碍，保留素材并明确报告。
- 需要交付视频时，目标是 MP4 加可编辑工程和复现所需素材。没有渲染或工程时不得标成已完成。手动完整观看并听声是最终审美 QA；脚本和 ffprobe 只能提供技术检查。
- 不自动发布。用户明确授权发布前，只交付本地/可审阅成果。

## 项目校验

完成或阶段性交接后运行：

```bash
python3 scripts/validate_project.py <项目目录>/project-manifest.json --root <项目目录>
```

只有确认本地素材路径时再加 `--check-files`。此脚本校验研究证据、断言引用、分镜时间线、素材状态和交付标记。渲染后可运行 `python3 scripts/inspect_render.py <视频.mp4> --expect-width 1080 --expect-height 1920 --expect-duration 30` 检查媒体元数据；按需加 `--require-audio`。脚本不验证来源真实性、不登录平台、不渲染视频，也不代替人工观看和听声。详细输入输出见 `references/handoff-contract.md`。
