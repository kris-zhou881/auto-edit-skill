# 竖屏 Skill 讲解视频规范

先遵守抖音项目的 [留存优先剪辑规则](douyin-retention.md)。本页只补充画布、排版和真实演示要求，不再规定固定片长、固定尾帧、互动次数或慢运镜。

## 画布与可读性

- 默认 1080×1920、30fps。用户指定其他比例时重新排版，不把横屏画面直接压缩。
- 主体、钩子和字幕避开平台常见的顶部、底部及右侧操作区。真实界面只裁切和放大关键区域，不改造网页内容。
- 主标题可从 80px 试起，正文 48px 以上，说明文字 36px 以上。每屏只留一条核心字幕，通常一至两行，每行尽量不超过 14 字。对比度应足够，不能遮住关键操作。

## 真实内容与封面

- 开头钩子必须能由本片的实际功能、演示或证据兑现。先准备事实镜头，再写与它相符的钩子。
- 编程和 Skill 视频优先用真实录屏、实际结果和逐步揭示的代码。重演内容要标明示意或实录回放，不能把动画当成实测。
- BGM 需符合抖音留存规则，许可范围清楚，人声优先。
- 成片后单独交付一条与开头钩子及真实内容一致的封面标题。画面封面使用真实成片或与本期有关的素材，不夸大结果或功能。封面尺寸和人物规则沿用 [抖音自动化 Skill 主文档](../SKILL.md)。
