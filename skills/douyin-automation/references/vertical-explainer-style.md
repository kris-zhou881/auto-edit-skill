# 20–30 秒竖屏 Skill 讲解视频标准

适用：本账号的短篇 Skill 成果演示和讲解。用户为某期另定风格时优先采用当期要求；不据此改动其他项目。真实界面只裁切/放大关键区域，不改造或伪造网页。

## 画布与安全区

- 1080×1920，30fps，20–30 秒。
- 顶部留 8%（154px），底部留 22%（423px），右侧留 16%（173px）。关键标题、数字、字幕放在 x<907、154≤y<1497 的范围，并留出描边/阴影余量。
- 此为经验安全区，需上传草稿后用手机核对；未获上传授权时标记待核验，不自动上传。

## 字号与配色

- 主标题≥80px 且粗体；正文≥48px；说明≥36px。低于36px的设计文字删除、放大或改图标。真实录屏中需读的区域通过裁切放大达到可读；不要求重写原网页全部文字。
- 底色米色 #F2EFE6；主色红 #D9503F、绿 #2F8C6F、蓝 #5A82A3、黄 #E3B84A。
- 每场景只选一种高对比重点色；重要数字用该色，其余深灰。对比不足时增加深色描边/底衬，确保可读。

## 节奏与动效

- 前3秒直接展示真实成品动画或结果，不放独立标题卡；全片≥40%时长展示真实成品或前后对比。
- 每1.5–2秒有换词、高亮、位移、缩放或数字变化；不得出现连续静止超过1.5秒。执行上以1.5秒静止上限为准。
- 每场景一个信息点，通常3–4秒；结尾单独保留≥4秒。
- 进场0.3–0.5秒，ease-out，位移≤40px；重点词1.1倍放大或高亮扫过，0.4秒。
- 全片至少采用两种持续动效：数字滚动、线条描绘、箭头流动等；放在注释/图形层，不影响真实界面阅读。
- 用共同元素承接转场（数字飞入下一场、同一图形放大换场），避免硬切；禁止只有淡入、之后完全静止。
- 结尾“定格”指主要构图和文字保持≥4秒；保留轻微高亮、箭头或背景动效，兼容静止上限。

## 版式与字幕

- 不连续两个场景采用相同卡片版式；从数字放大、左右对比分屏、流程动线、成品演示、大字金句中选用，仍以真实演示为主、少文字卡。
- 主体宽度占画面≥80%，位于中上至中间；主体铺宽可作为背景，但关键文字必须遵守右侧安全区。
- 每屏字幕≤14字、最多两行，手动断句，避免孤字；关键词用当场重点色。字幕右边界不进入按钮区。

## 互动、声音与封面

- 0–3秒结合结果提出一个二选一问题；约12秒提示“想要哪种，评论区告诉我”；结尾关键词放大，保留≥4秒。至少三个互动点。
- 只有确有可交付资料且用户愿意兑现时才写“评论后我发你XX”，否则改为不承诺发资料的真实互动。结尾关键词与拟写的置顶评论一致；发布、评论或自动发资料仍需明确授权。
- 人声清晰优先；背景音乐比人声低12–15dB；峰值≤-1dBFS。保留实际音量测量结果。
- 封面用真实成品画面加≤10字结果型大字；沿用横版1440×1080、竖版1080×1440及固定人物规则。

## 交付前逐项记录

- 前3秒有成品/结果；真实成品或对比时长≥40%。
- 无超过1.5秒的静止；两种持续动效；场景信息点与版式符合要求。
- 最小设计字号≥36px；字幕无孤字、不压按钮区；关键内容在安全区。
- 三个以上互动点；结尾构图保持≥4秒且有轻微动效；资料承诺真实。
- 音量和峰值达标；封面字数、尺寸正确。
- 手机草稿复核记为已做/待做，不能用桌面检查冒充手机核验。

新增执行要求见 `creative-quality.md`：每1.5秒的变化通过有意义的字幕、高亮或演示推进实现；不为凑频率堆特效。结果开场与钩子同时兑现；结尾资料承诺仍须真实。
