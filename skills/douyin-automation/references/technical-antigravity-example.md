# Antigravity Skill 系统

这是完整制作流程的脚本演练，用来检验交接。来源已核对，录屏、动效、导出和作者审看仍由实际制作运行完成。

## 输入和证据

- Skill 名称为「Antigravity Skill 系统」，目标是让观众看懂项目级 Skill 的发现方式和实际作用。以 Antigravity App 为演示对象，设计 30 秒竖屏。
- 官方文档核对项目级目录 `.agents/skills/<skill-folder>/`，App 可按描述自动选择相关 Skill，也可输入 `/<skill-name>` 明确调用。脚本采用显式调用以便观察，自动选择只画原理。SDK GitHub 示例作为补充参考，只用于确认目录包的概念，镜头不把 SDK 调用方式说成 App 的用法。[Antigravity Agent Skills](https://antigravity.google/docs/skills) · [官方 SDK 示例](https://github.com/google-antigravity/antigravity-sdk-python/blob/main/skills/google-antigravity-sdk/examples/getting_started/agent_skills.md)
- 构造自有示例 `verify-totals`，指令是读取本地示例表并返回固定格式的合计，不需第三方安装、授权页或外连服务。用虚构销售数据 12、15、18，预期合计 45。即便数字正确，也要看到界面中确实调用了该 Skill，以及输出符合指定格式。

## 脚本、素材和镜头交接

| 时间 | 口播和主张 | 素材、采集及动画 |
| --- | --- | --- |
| 00–04 | 「同一份表，我让它按固定格式给出合计。」 | App 实际结果特写。先跑一遍有 Skill 的示例，录下可验证输出。 |
| 04–09 | 「这个规则，就放在当前项目的 Skill 文件里。」 | 真实终端列出目录，切进 `SKILL.md`。录制原始命令和输出。 |

| 17–21 | 「相关任务可触发它，我这里直接点名调用。」 | 独立动画，依次出现任务、Skill、结果，点亮当下讲解节点。标注流程示意。 |

## 从初剪到审核

1. 先核对项目作用域、技能发现、显式调用和输出格式四个点。把官网、终端、IDE 和 App 资产分别标为文档、终端、代码和界面。若实测调用未显示或合计不对，保存失败证据，压下开头的成功主张。
2. 本期动作与真实输出先审，再制作四秒流程动画。用已获准的剪映免费口播，按实际音频对齐高亮，试剪开头 10–15 秒后完成初剪。
3. 跑三层质检，预期产生 00–29 秒的 30 张帧图。若作者在 00:12 发现描述行被裁切，报告该时间点，放大并改变取景，把无关行移出画面。重导后对新哈希重跑三层检查。
4. 作者检查切镜是否踩句、实际调用和合计是否正确、四个核心点是否完整。三项批准后生成发布包。这个示例没有代做作者审批或发布。
