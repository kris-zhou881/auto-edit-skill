# 真实素材与代码动效剪法

适用于用户要求按真实网图、鲜明图形和程序动效做拆解类短片。以参考片中可观察的剪法为依据，口播里关于作者做法、比例和效果的陈述只记为作者自述。

## 先拆参考，再选题与写稿

- 去掉录屏播放器和黑边后看内容。记录实际附件时间、倍速、画面构图、主角、字幕位置、变化触发点和声音。逐段把参考片与旧片按同一种叙事任务比较。没有原速素材时不推断原片配乐节拍或镜头密度。
- 钩子用真实结果提出一个具体反差。技术工具用一句大白话说明作用，再用简单例子实测。选题优先挑有可公开复用的真实素材、有可复现的输入和输出、两者能形成反差的内容。无目标平台数据时不称为热点。
- 当前参考的可迁移审美：暗色证据段用高反差与少量强调色，浅色解释段用留白和紧凑的图形关系。照片或结果做第一视觉重心，短字幕独立于证据，颜色用于表达当前状态。按本期题材设计配色，每镜只留一个视觉主角。参考是横画幅演示的手机录屏，新片按 9:16 重新构图。

## 逐句选镜和做动效

每个口播节拍记录「要说的事实 → 能支撑的素材 → 画面变化 → 动效组件与触发词」。用实际配音定切点。每段可以由多个镜头完成，一镜只讲清一个动作。按以下意图选组件，在短样中验证出场、状态变化和结果。

| 句子要做什么 | 主画面与组件 |
| --- | --- |
| 交代对象、现象或反差 | 有来源的真实照片或实录为主，局部推近、框出细节或揭示实测标签 |
| 解释名称、状态或前后变化 | 让文件、人物或按钮图标完成换标、分离或重组，同一镜内明确前后状态 |
| 解释关系、顺序、流向 | 按旁白依次长出连线、点亮节点、沿边移动，图标的位置与动作有含义 |
| 给出数据、对照或结论 | 保留真实输出、图表单位和口径，按说到的值揭示或高亮。单独拍出操作与结果 |
| 收束应用 | 用新证据或一句操作提示结束，停止引入新概念 |

- 真实网络照片、视频逐个打开来源页，核对画面、作者和使用许可，记录来源 URL、权利说明、素材身份与本地路径。下载的不同尺寸、裁切、推拉和变速版本都继承同一个素材身份。每张照片全片只用在一个连续镜头；每个视频源区间在全片只用一次，不重叠回剪。用新角度、新素材或拆开构图解决同说多次的问题。单镜内的有意运动不算复用。
- 把照片、实录与动效合为同一个叙事镜头时，证据主体保持可见、可读。解释关系时让图标移动、变形、连接或反馈，图标动作必须兑现这句口播。禁止给静态卡片统一加进场就算动效，也不要用同一整页改高亮冒充不同镜头。
- AI 写可复用动效组件，由代码按帧控制。每个组件记录适用意图、真实输入、时间点、可调排版和输出轨。先按内容选组件，再谈转场；剪映负责现行约定的口播与总装。独立保留预渲素材、字幕、配音和可编辑工程。
- 技术片真实占比按主导画面的实际时长计算，许可清楚且确实支撑本句的外部真实照片、视频、截图可与本地实录一起计入。程序重画的输出即使来自真实数据，也标「实测回放」，按动效计；用原始截图或录屏作主画面可计实录。参考片提及的阈值、色盘及效果只在本期设计采用时使用。

## 试剪与验收

先试一个真实证据段加一个组件动作，再做全片。抽帧审可读性、裁切、安全区、黑屏和冻结。按素材身份核对整片复用，逐句确认主画面兑现旁白、图标动作发生在对应词附近、结果停留足够阅读。连续看听再验声音与节奏。中间渲染与剪映实际导出分别标记。
