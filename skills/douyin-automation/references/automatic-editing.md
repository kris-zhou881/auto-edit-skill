# 自动剪辑与质检

## 制作顺序

选题 → 候选钩子与真实视觉证据 → 口播 → 分镜 → 素材匹配 → 分句配音 → 从实际语音生成时间轴 → 逐镜剪辑 → 字幕 → 音乐音效 → 预渲染 → 自动质检 → 人工看听 → 交付。

1. 开场三秒直接给结果、问题画面或前后对比。每句匹配一个真实可读的结果或操作，语义变化才换镜。优先录屏、实拍、操作演示；图表和检测数据用于说明可量化结果。日志回放应标明是回放。素材缺失应先补拍。
2. 复制 `templates/shot-plan.json`。逐镜填写来源、切入点、口播、字幕、强调、转场、声音和构图。开始和结束由实际人声加短停顿计算，以生成的音画时间轴为准；中途换配音须重算后续镜头。静态概念卡或旧稿反例每镜最多四秒，合计不超过四分之一。
3. 运行 `python3 scripts/auto_edit.py <分镜方案.json> <输出目录>`。依赖 macOS、Swift/AppKit、FFmpeg/ffprobe、Python 3.11+。默认须填写剪映实测音色名与证据路径，并提供每镜从剪映生成的独立 `voice_file`。仅内部画面验证可显式使用本地占位音，产物须标为内部预览。无剪映许可证据时不能写为剪映素材。配乐可省略，添加时提供有许可的本地文件。
4. 先跑 10–15 秒试剪，检查静音、字幕、画面和音画同步。试剪合格后再跑目标时长。退出码非零时查自动质检报告。脚本最多尝试两次，可用 `retry_in`、`retry_caption` 调整问题段，并降低配乐；素材缺失、语义、持续静止或重复失败时更换对应素材或重配再跑。失败产物保留为待验收文件，只有通过才写自动验收 MP4。任何新导出要跟原生剪映最终文件分别记来源。
5. 输出包含逐镜无字幕画面、独立口播和配乐音效 WAV、SRT、字幕 PNG 和带实际时间戳的分镜，供剪映组装。剪映工程交付需装入实际时间线并验证能打开。另由人从头看听，核实真实证据、字幕可读性、配音自然度和配乐；自动通过不代表观感通过。

## 阈值和范围

- 画面 1080×1920 / 30fps。右侧和底部使用保守安全边距。字幕托在不透明深色底上，每镜最多两行，每行最多十四字，并实测像素宽度。主体素材绘制区与字幕互不相交。画面裁切是否丢了操作区域需看画面复核；平台实际 UI 随设备变化。
- 音轨和视频时长允许差 0.12 秒以内；人声轨和成片分别找低于 -42 dB 持续至少 0.8 秒的静音；末句后保留 0.03–0.65 秒。
- 视觉以每秒六帧抽样，检查黑暗或空白、持续低变化和字幕像素对比。字幕最低亮度对比阈值 4.5:1。低变化不等同于无信息，合法的概念卡与旧稿反例单列。整个成片视频与音轨做严格完整解码。
- 配乐音效平均至少低于口播 12 dB、峰值不高于 -24 dBFS，成片峰值不高于 -0.5 dBFS。曲风、自然度和心理声学遮蔽仍需听审。
- 剪映重新导出意味着此前的哈希与自动报告不再覆盖新文件。应针对实际新文件复检再验收。

## 参考视频对齐

- 记录参考链接、观察时间码与证据来源，分别核对镜头、转场、点击反馈及声音。浏览器显示正在播放音频只说明播放器状态，不能据此填音效时间；参考内容有缺口时，试剪只做已验证的部分，整片等对齐验收后再做。
- 方案可选 `caption_style: "capsule"`；每镜可用 `caption_keyword` 标出字幕里实际存在的关键词。单行宽度超出安全区会拒绝渲染。
- 运镜 `push` 是 12 帧内轻推近 6.5%；需要浅色短转时可用 `light_dip`，默认仍用硬切。不要在普通换句时统一套动效。
- 操作镜可用 `click_event: {"frame":14,"x":710,"y":758}` 和 `sound: "click"`；坐标是 1080×1920 画布像素，帧从本镜第 0 帧算起。素材本身必须能说明操作因果。光标、目标高亮、推近起点和独立音效轨读取同一个事件；点击声为原创提示音，可替换，不能冒充参考原声。

- 背景随参考镜头阶段切换。手册/操作段可用 `editorial_light`（全片或逐镜 `backdrop`），用浅白蓝渐变、边缘点阵和细线，保留前景内容对比；实拍段使用对应实拍素材。背景音乐和点击声分别按参考可听时间点对齐。
