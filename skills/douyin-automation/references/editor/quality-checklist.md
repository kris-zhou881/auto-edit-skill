# 交付质量清单

## 风格与内容

- [ ] 参考资料范围和未访问内容已说明。
- [ ] 开头有真实成果、清楚看点，文案和画面匹配。
- [ ] 每个功能都来自真实测试，脚本与镜头表先于录制。
- [ ] 操作清楚、解释易懂、节奏有变化；没有无效等待和虚构效率数据。
- [ ] 与样本逐项对照：开头、叙事、镜头、录屏、字幕、音效、转场、封面、信息密度、整体观感；指出具体差距并修正明显问题。

## 安全、许可和剪辑

- [ ] 仓库、固定版本、许可证、依赖和危险权限有记录。
- [ ] 静态审查、安装、运行结果分别记录；没有冒充通过。
- [ ] 录屏真实且清理个人信息。
- [ ] 使用剪映专业版完成正式剪辑；无会员素材、破解或授权不明素材。
- [ ] 音画同步、口播清楚、字幕无错字且不遮挡关键 UI。
- [ ] 剪映工程能重新打开；如受阻，未把其他工具导出冒充剪映成片。

## 文件与技术检查

- [ ] 导出文件存在时核验实际分辨率、比例、帧率、时长和编码信息。
- [ ] 从开头、中段、结尾抽帧检查黑屏、卡顿、裁切、字幕和封面一致性。
- [ ] 检查音轨是否存在、峰值/响度是否削波，并人工试听口播与配乐。
- [ ] 9:16、3:4 封面在小尺寸下标题仍可读，并报告实际像素尺寸。
- [ ] 发布文案和标签符合平台格式；没有发布动作。

未实际核验的项目写“未检查”，不得打勾或写通过。


## 创意质量门槛（当前账号）

- [ ] 三种不同开头有真实兑现方案，选中钩子的素材已就绪；前3秒有成果和吸引点。
- [ ] 口播短句口语化，有悬念/反差、停顿和情绪变化；实际试听无明显机械感。
- [ ] 每镜头画面、花字、动效、转场、配乐、音效、配音情绪都有具体设计或有理由的留白。
- [ ] 桌面剪映可操作，实际免费资源与许可已检查；字幕不以黑底白字为默认。
- [ ] 六项 creative_review 均有时间码/观察，问题已返工；报告对应当前导出。
- [ ] --stage final --check-files 通过；该结果只证明记录/文件门槛通过，不代替看听。
