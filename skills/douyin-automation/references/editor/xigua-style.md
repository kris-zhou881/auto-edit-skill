# 「西瓜同学🍉」风格制作规范

## 证据范围

依据此前对抖音主页的核验和 7 条实际打开的视频样本：App/小程序交互、Dashboard 交互与审美、网页/Skill 实测、AI 工作台。主页当时显示 101 条作品；其余作品未逐条观看。样本时长约 1:51–5:05，不能把结论说成全账号逐条统计。精确转场频率、口播音色和逐镜头时间码没有可靠记录，不作推断。

这些是有限样本中的历史观察。当前抖音项目须优先执行 [留存优先剪辑规则](../douyin-retention.md)，旧样本的片长、镜头节奏和结尾形式不构成要求。

## 可迁移的共同规律

1. **先给结果和问题。** 前几秒尽快出现真实 UI 或交互效果，再用简短问题/观点说明看点；不要先长篇介绍背景。
2. **让复杂功能变成可见案例。** 把 Skill 放进一个具体任务里，选 3–6 个观众能看懂的变化，逐项演示并解释价值。
3. **结果—原因—实测—复现。** 用首帧钩子开场，5 秒内讲清能解决什么并给出实际操作或结果；随后补关键方法和限制。按留存规则用相关问句收尾。
4. **让操作本身承担叙事。** 画面重点是按钮、卡片、页面、数据或状态怎样变化。每次讲一个因果，让观众能看清操作前后。
5. **信息量高但层次清楚。** 样本常用章节标题和要点辅助较长的逐项讲解；按本次内容选时长，不硬压成 35–60 秒，也不为凑时长重复演示。
6. **字幕清楚、不过度设计。** 样本可见较大的白色字幕，部分使用深色圆角底；放在中下部并避开关键 UI。不要把某一种字体、动画、口播声线或转场写成固定规则。
7. **构图服务于产品。** 常见竖屏中央展示手机、网页或显示器，必要时以模糊画面填充左右空间；实际界面风格会随案例变化，有深色、浅色和奶油色。账号统一感主要来自演示版式和讲解结构，不是固定黑色霓虹主题。
8. **封面标题简短具体。** 样本常用数字、明确收益或痛点词，如“6种”“3种”“高级感”“告别模板感”，并搭配真实产品画面；黑、黄、白是部分封面的表现，不是硬性配色模板。
9. **结尾问题需对应本片内容。** 最后一句必须是具体评论问题，问完即收。不要声称每条样本都有相同结尾口播。

## 单期执行模板

按留存优先规则重排，不能沿用本历史模板中的时长、慢铺垫或固定 CTA。

- 开场：首帧直接给真实问题、冲突或结果，并用清晰钩子与画面同步；2–5 秒内立即兑现。音效只在有明确动作或节奏落点时添加。
- 逐项实测：展示 3–6 个关键场景，保留能证明结果的操作与反馈，剪掉等待和无效鼠标移动。
- 方法与限制：展示安装/关键设置或提示词；指出失败、边界或与预期不同之处。
- 收束：最后一句提出与本片直接相关的问题，问完即收。

## 禁止的风格误读

- 不要预设黑底、霓虹、电影广告、赛博朋克或统一滤镜。
- 不把概念截图、AI 生成界面或素材库预览说成实际运行结果。
- 不为模仿而复制原作者的文案、封面、配乐、画面和未授权素材。
- 不虚构镜头秒数、转场频率、互动数据或配音特点。需要精确镜头表时，只对可访问的参考视频逐段记录时间码。


旧样本的白字/深色底描述是观察记录；本账号当前制作以 douyin-retention.md、vertical-explainer-style.md 和 creative-quality.md 为准，优先合适的免费花字/关键词强调，不把黑底白字或某种花字固定套用每镜头。
