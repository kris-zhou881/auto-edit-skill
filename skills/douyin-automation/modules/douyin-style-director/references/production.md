# 本账号创作条件

抖音短片先执行主 Skill 的 `references/douyin-retention.md`。0–2 秒首帧直接给真实钩子，2–5 秒兑现核心信息，单镜头尽量不超过 3 秒，末句为相关问句。不加慢推拉、空镜、长片尾；旧模板与本页通用节奏说明不得覆盖当期规则。

目标为 GitHub 实用 AI Skills 的科普、推荐和实测；竖屏 9:16、不露脸，可拍手部/MacBook/键盘/桌面，有真实录屏及可能存在的三段实拍。先逐一核实素材路径、内容和质量；不能凭文件名认定是指定三段。

开头第一帧就给可验证的变化、结果、冲突或真实痛点，避免空镜和泛泛宣称。中段持续给新信息，结果兑现不能无故拖到末尾；这些是创作假设，不是留存率保证。录屏必须可读且真实；商业质感由布光、稳定、构图、素材质量和克制的后期共同建立。Flow 只为实际拍不到且能帮助理解的镜头设计提示词，并标明“概念画面”；使用前须获得用户对积分消耗的授权。

旁白短句尽早兑现开头。字幕只保留核心短句，画面简洁。人声优先；BGM 短促有节奏且明显低于人声，不用平缓抒情曲。最后一句是相关问题。每期改变钩子、视觉比喻、镜头顺序和转场选择，保留经过多片证实的风格原则。

## 用户已确认的抖音制作规范

- 开头放大真实网页或产品里的关键词；中段展示真实滚屏和短字幕，少用纯文字卡。录屏必须来自本次真实页面和操作。
- 竖版成片使用 9:16。横封面为 4:3（1440×1080），竖封面为 3:4（1080×1440）；分别检查裁切后人物、标题和主体。
- 需要封面人物时，使用用户提供的卷发、细黑框眼镜男生参考；场景、动作、表情、光线、服装与构图可按题目变化。封面夸张但不能歪曲金额、功能或实测结果。
- 配乐、音效与转场优先使用免费且许可覆盖目标平台的素材，保存来源；音乐压在口播下面。许可不清楚时不使用。
- 原始素材、录屏、封面、工程、字幕和成片默认保存在桌面「视频」目录的项目子目录；用户另有指定时按本次指定。
