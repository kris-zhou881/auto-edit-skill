# 参考视频分析规范

先登记原始链接、账号身份、作品链接、取得方式和权利状态。网页标题、封面、互动量只用于选片；风格结论必须来自实际视频。建议选 3–5 条在主题、结构和制作方式上有代表性的作品；公开互动数据只作辅助，附抓取日期。

逐条观看并听声，至少记录九组观察：①前 1/2/3 秒与信息排序、主题揭示、成果兑现及收尾；②镜头长度分布、景别、主体位置、运动、实拍/录屏关系；③曝光、黑位、高光、色温、饱和、材质、锐度，分清拍摄与后期；④切点、停顿、节拍与信息密度；⑤实际转场的起止、视觉目标、实现和禁用场景；⑥字体、层级、布局、强调、进出场与声音同步；⑦音乐能量、旁白、环境音、音效与静音；⑧可能影响前 2 秒和完播的结构，但效果标为假设；⑨稳定特征、偶发手法、单片创意与不应复制的素材。

`analyze` 给出 `probe.json`、`shots.json`、`timeline.md`、`keyframes/`、`contact_sheet.jpg`、`waveform.png`。场景检测受渐变、屏录变化、遮罩和运动影响，切点须逐帧复核。波形不证明节拍，BPM 应人工听辨或用可靠节拍工具二次核实。关键帧只是抽样，复杂效果要回看原片。

运行 `profile-init <档案目录>` 生成九个档案文件，已有档案不会被覆盖；填写后运行 `validate-profile <档案目录>`。`style_profile.json` 的每条规则都包含 `feature`、`sources`（作品、起止时间）、`visual_audio_evidence`、`conditions`、`implementation`、`avoid_when`、`confidence`、`status`。`status` 只用 `observed`、`inferred`、`pending`；没有参考 MP4 时保持空规则和 `pending`，不得把模板说明填成博主结论。共性需至少两个独立作品支持；单片证据按“该片观察”保留。
